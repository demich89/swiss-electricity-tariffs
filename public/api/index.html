FieldMeaning


fetchedAt / staleAfterUTC ISO 8601: last successful fetch and provider-specific expiry.


start / endUTC Unix milliseconds. Start inclusive, end exclusive.


tarifflow or high. Outside the intervals, the tariff is unknown.


timezoneUse Europe/Zurich for display and local day boundaries.




JavaScript example
Works in Node.js 22+. In browsers, access from another website depends on the hosting CORS headers. The tariff website uses the same origin.
For stale data, show a warning or reject the data in your application. Never extend an expired interval. A missing interval means unknown, even if the previous tariff was low.


Usage guidelines
This is a static read API: no authentication, query filters, writes, historical archive or live server calculation. Query parameters do not filter the snapshot. Filter locally for your period; account for 23-hour and 25-hour days.
Poll at most once every five minutes and use a timeout. Check the HTTP status and JSON structure. If a fetch fails, the previous publication remains available; availability is not guaranteed. Existing v1 fields and meanings remain stable; new fields may be added. Breaking changes receive a new version path.
